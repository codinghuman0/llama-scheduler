# Frozen A component attribution

One campaign, four arms, 64 measured visits. Every visit starts a fresh server, one excluded warmup and one measured atomic eight-prompt cohort. Historical cohorts heldout-1/2 are previously observed. CPU envelope, exact numeric prompts, B0 output oracle, runtime/DSOs and load protocol are inherited unchanged.

Two S cpu25 admission visits precede six Linux smoke visits (three arms x two cohorts). Each contains warmup plus excluded correctness check. Source/runtime/scheduler code is never modified. A safety failure before timing permits the predefined Linux-only branch; no such switch or replacement after timing.

The primary is actual generated tokens / whole-cohort HTTP wall time. All four arms are paired within condition/cohort/block. Bootstrap resamples four complete blocks per cohort at equal weight, using identical block samples for all five contrasts: 10000 replicates, seed 20261122, linear percentiles. One campaign; no optional stopping or extra repeats.

A_S/B0_L: both conditions mean >=5%, lower >0%, faster >=6/8 is scoped one-campaign success. E and S component effects have no 5% threshold. Equal choices cannot establish a worker-choice benefit. S-mediated changes in E choice must be reported as integration. No fixed6_S/fixed5 arm; not full factorial or superiority over every static configuration.

The fixed condition/cohort/Latin arm sequence is generated by code/freeze.py and written before timing. A missing or invalid visit stops the campaign and leaves all subsequent visits NOT_RUN. Exact B0 oracle equality, strict no-cache/token counts, all ELF inode/hash aliases, actual policy/fixed affinity and controlled-load consumption are checked. CPU seconds is not energy; nonstream TTFT is unavailable.

Same 0.5s minimal process/state watchdog in every arm. S retains existing FULL diagnostics, kernel-log guard, selected-child launcher and cleanup. Read-only BPF inventory occurs before warmup. Fixed affinity only; old dynamic-affinity failures remain unresolved. No competing build or measurement. Full runtime commands and replacement environment are in cases.json; command-port substitutions are recorded for each visit.

After the registered campaign: independent raw recalculation, protection check and review package. Next research step is one separate independent reproduction of the component campaign, not more optimization.
