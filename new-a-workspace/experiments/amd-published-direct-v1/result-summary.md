# 배포 통합본 AMD 성능 확인

**`CONFIRMED_SYSTEM_GAIN` — AMD Ryzen 5 5500U의 8요청 동시 처리량.** 배포 통합본은 역사적 원본 B0 대비 ambient에서 평균 **+17.92~18.11%**, `cpu25`에서 **+32.88~37.43%**였다. 각 캠페인·조건에서 유효 8/8쌍이 빨랐고, 네 95% paired bootstrap 구간의 하한이 모두 사전 목표 5%를 넘었다.

GitHub `codinghuman0/llama-scheduler`의 [`integration-v2` 커밋](https://github.com/codinghuman0/llama-scheduler/commit/fcb2e082f50beb4d4f91d1b303b3240663fa0f03)은 측정 시점의 통합 체크아웃과 일치했다. 실험 코드는 저장소 안의 `new-a-workspace`에서 실행했다. B0는 `7a2db1a0cf38e5f4eb278a58c3903d295258d0ea`의 보존 재빌드다. A는 이전 R/E 검증본이며, I는 배포 소스의 fresh OpenMP release 빌드와 `integrated-runtime-research` 프로파일이다.

## 기존 개선과 통합의 추가 변화

| 캠페인 | 부하 | A/B0 평균 변화 | I/A 평균 변화 | I/A 95% 구간 |
|---|---|---:|---:|---|
| 1 | ambient | +17.44% | +0.57% | +0.08% ~ +1.01% |
| 1 | cpu25 | +33.79% | −0.68% | −2.02% ~ +0.54% |
| 2 | ambient | +17.14% | +0.68% | +0.04% ~ +1.67% |
| 2 | cpu25 | +36.77% | +0.49% | −1.32% ~ +2.34% |

기존 A가 이미 원본 대비 개선분의 대부분을 확보했다. 새 통합의 ambient 추가 변화는 약 0.6~0.7%로 두 캠페인에서 작게 양수였다. cpu25에서 추가 변화는 방향이 엇갈렸고 두 구간에 0%가 포함됐다. 각 모드의 서버 총 CPU 시간과 블록별 재계산은 공식 JSON에 있다. I/A는 역할별 pool, state-v2와 배포 소스 조합의 추가 변화이며 phase 정책 단독 기여는 `not-isolated`다.

## 정확성, 부하 및 적용 범위

- 동결된 두 새 요청 세트와 32개 블록으로 확인 96방문을 완료했다. 워밍업과 본 측정에서 32/32블록의 세 모드 생성 ID가 일치했다. 요청당 128토큰, 방문당 1,024토큰이었다. 실제 본 측정 생성량은 총 98,304토큰이며 앞선 smoke 방문은 통계에서 제외했다.
- 모든 방문의 모델, 프로젝트 DSO, 공통 `libgomp`, 물리 코어 6개와 `SCHED_OTHER`를 입증했다. 원본 모델, CPU 전용 OpenMP, AVX2, 생성/배치 5/6 및 공통 서버 옵션을 유지했다. I의 역할별 pool 적용과 R Prefill 기준 경로는 시작 및 완료 로그에 있다. 캐시 재사용은 모든 응답에서 0이었다.
- cpu25는 CPU10 한 코어에서 동일한 프로세스로 가했고, 측정 구간의 실제 소비는 0.25094–0.25311 core였다. 모드별 평균은 B0 0.25149, A 0.25256, I 0.25237 core다. 부하 및 서버 프로세스는 정상 종료했다.
- 효과의 범위는 이 장비, 모델, 동일 8요청 도착 방식의 CPU 처리량이다. 커널 경로 상태는 `sched_ext disabled`였고, 앞선 native `m4` 토큰 지연 실험은 별도 기록이다. 본 결과는 기본 Linux 위에서 배포 통합본 userspace 런타임을 비교한 것이다.

## 재계산과 증빙

`new-a-workspace/`에서 `python3 -B experiments/amd-published-direct-v1/recalculate-retained.py`로 원본 측정 장비에 보존한 원시 HTTP 응답과 시간 데이터를 다시 계산할 수 있다. 이 명령은 저장소에 이미 들어 있는 분석 도구를 동결 해시와 대조해 사용한다. 같은 성능 실험을 새로 실행하려면 당시의 보존 B0/A 런타임이 별도로 필요하다. 모델 없는 topology·SSE·integration 테스트 76개도 통과했다.
